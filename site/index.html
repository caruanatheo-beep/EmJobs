Une entreprise à ajouter ?

Em Jobs lit directement les sites carrière des entreprises. Pour en ajouter une :

  1. ouvre une suggestion avec le nom de l’entreprise et le lien de sa page carrière ;
  2. elle est ajoutée au fichier des sources, puis le site se met à jour tout seul.
Proposer sur GitHub ↗

La suggestion est publique et demande un compte GitHub gratuit. N’y mets aucune donnée personnelle.
